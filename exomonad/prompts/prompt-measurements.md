# Prompt measurements

These are proposed measurements, not collected evidence. Use existing run
traces and sampled reviews; do not add a telemetry subsystem for this.

Compare the complete assembled instructions on tasks with inspectable outcomes:
a runtime failure with competing explanations, a structurally analogous problem
using different vocabulary, and a bounded edit where extensive investigation
would add little. Retain source revisions, prompt identities, typed requests, tool
capabilities, decisions, checks, and final artifacts. Check whether the agent's
first useful action, method, and adaptation fit the evidence available at the time.

- **Decision value:** identify which observation changed a consequential choice,
  whether a cheaper discriminator existed, and whether work was reallocated when
  an assumption failed.
- **Transfer and limits:** inspect whether agents find related failure mechanisms
  beyond named targets and reject analogies missing the required relationship.
- **Sensitivity:** supply a known failure or controlled mutation where appropriate;
  inspect whether a quiet procedure can detect it and whether a failed sensitivity
  check leads to investigation repair rather than a product conclusion.
- **Handoff quality:** have a recipient reproduce or decide from the delivered
  artifact and its retained evidence. Track missing preconditions, unresolved
  hypotheses presented as findings, and local checks mistaken for combined acceptance.
- **Orientation calls:** count `doc`, lookup, and status calls spent locating
  guidance or checking mechanics, grouped by task type.
- **Rejected cells:** count admission rejections and the number of repair cells
  before a useful result, separating syntax/type errors from unclear contracts.
- **Unnecessary model workers:** record agents admitted for work a pure
  function, known effect sequence, Jev judgment, or record actor could handle.
- **Composition adoption:** sample whether proven repeated notebook sequences
  become named helpers or modules when a production consumer appears.
- **Missed questions and obligations:** count child questions unanswered before
  the owner's next decision and accepted obligations absent from final delivery.

Compare rates and task context before and after the prompt baseline. Preserve
task outcomes, not just call volume: fewer discovery calls are useful only when
rejections, missed questions, unnecessary workers, and incomplete delivery do
not increase.

Where a cue's contribution is uncertain, compare trials with and without it on
matched tasks and capabilities; retain variability and counterexamples. Judge
resulting decisions and artifacts, not the presence of expected vocabulary.
An editorial walkthrough suggests what to test; it is not an execution trial.
