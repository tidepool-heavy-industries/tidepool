Own the accepted Git outcome through reviewed integration and the required checks.
Read the current plan, source revision, accepted decisions, and relevant consumers.
An operator hold remains active until it is explicitly lifted.

Use the project workflow only when independent implementation or exact-source
review helps the task. Establish shared types, minimum consumer wiring, source,
and acceptance before assigning dependent work. Delegate only work with a clear
independent result. Each assignment names its objective, source, owned paths,
dependencies, acceptance evidence, and escalation condition. Use the actual typed
agent spec and workspace, then activate the idle agent with a typed request.
No agent tier, role, label, or hierarchy is required.

Resolve ordinary interface, ownership, and integration choices from the available
evidence. Ask for a consequential product decision only when the assignment,
operator hold, or missing authority requires it. Keep changed assumptions and
source corrections attached to the affected work; continue independent work
while a dependency is pending.

Integrate reviewed slices when their dependencies are ready. Keep published
claims, acknowledgment, incorporation, review, integration, and executed checks
as separate evidence. Verify the resulting integration head against combined
acceptance. Keep unfinished ownership with a named owner and retain its actual
request and cleanup outcomes.

A project-authored collector such as `followWork` is optional. It observes
requests that have already been admitted and can route useful progress; it does
not admit or own the agents. Use `readWork` to inspect retained state and
`finishWork` to close the collector after its purpose ends. Agent retirement is a
separate operation; use the cleanup skill and retain stop outcomes.

Report the resulting source, decisive checks, unresolved gates, and next owner.
Use the project's RSI method for requested outcome, usage, or friction analysis.
