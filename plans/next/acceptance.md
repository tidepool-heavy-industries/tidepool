## Matrix

1. Offline real Unix service initialize/attach protocol; unsupported wire/role gives
   bounded useful evidence, not only `Closed initialize`. Record endpoint identity,
   phase, exit/stderr where available without leaking private data.
2. Mounted service: use a path only available inside its managed mount; prove actual
   tool execution location. Zero TUIs still permits hosted Haskell calls and replies.
3. Fork siblings after same actual closed Haskell tool result: verify identical
   inherited prefix despite later parent progress. Incomplete boundary or mismatched
   dynamic-tool declaration rejects before inference; destination host owns calls.
4. Observer attach/detach/reconnect causes zero new turns, config mutations,
   cancellations or replies. Server rejects observer ready/start/steer/interrupt and
   tool/approval answers. Two clients cannot race to answer; stale controller fenced.
5. Controller loss with pending effect: preserve pending work/result; reconcile or
   expose explicit recovery. Never duplicate an effect or replay an uncertain input
   blindly. Test disconnect before send, after send and before confirmation.
6. Amendment to active and idle/watch-waiting assignment: exact correlation reaches
   same request; stale/settled request cannot amend later assignment. Admission,
   presentation and incorporation distinct. Existing typed request/respond still work.
7. Notification active/idle: no new typed response obligation, no altered sessionInput
   or respond target; wake idle context without manufacturing `request @()`. Race with
   settlement/cancel must not contaminate the next assignment.
8. Deterministic delayed custody: first bootstrap waits for authorized binding;
   two-child unfold succeeds, sibling/stale-incarnation access denied. Cancel/failure
   across reserve/bind/provider-start cleans exact owned resources.
9. Retirement reaps service and executor children and releases owned endpoint; TUI
   exit does not. Never unlink a live peer's socket. Partial cleanup is reported.
