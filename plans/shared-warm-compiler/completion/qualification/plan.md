## Wave Q1: prove the joined route early

Run this as soon as engine/output/runtime contracts join, before expanding the
test matrix. Retain source, actual compiler origin, world/base/successor identities,
operation/item IDs, transaction END, accepted runtime delta and final publication.
Observations must show the production path; an API called only by its new test is
not sufficient.

1. Use a genuine nonempty three-root source world, the production package profile,
   the actual source issuer and an imported `Seed` module. Execute a first binding
   and a second ordinary cell using it; both cells import the required module.
2. Prove private successor advancement and final atomic bindings/world association.
   Inspect actual returned values and exact native dependencies, not only IDs.
3. Repeat through the ordinary actor tool. Cover declaration, explicit and empty
   import, expression observation, mixed cell, source-defined retained value type,
   shadow/removal and a later invocation of an earlier retained continuation.
4. Evict only the test-owned predecessor realization and remove only disposable
   first-operation output after its owner releases it. Reuse through the successor;
   immutable source/native product custody remains retained. Then replace its worker
   and restore the same logical world without source/effect replay.
5. Exercise one real compiler failure, stale publication, source revocation and
   uncertain END. Verify no speculative public names, truthful completed effects,
   preserved prior committed values and no retry of accepted uncertain work.

The first two-cell pass is useful progress and the time to start bounded profiling.
It is not permission to claim every cell form or the final campaign works. Inspect
the actor/startup/renderer/recovery call graph when the finite route is deleted;
compile all direct consumers so a surviving backdoor cannot hide in test code.

tracing; bounded detailed runs expose phase/counter attribution and their observer
overhead. Record unknown counters as unknown. Do not add whole-graph walks to
measure how much graph walking was removed.

Start with real new-engine two-cell/AABA observations; publish preliminary timing
even if a later scenario fails, with the failure and unobserved intervals intact.
Once stable, compare matched prepared profiles and workloads with a retained
baseline. Calibrate then predeclare repetitions, cold/hot preparation, contention,
outlier treatment and useful benefit/resource criteria. A failed baseline remains
a failed baseline: compare only equivalent completed spans or state that no valid
whole-workflow speedup can yet be calculated. Tenfold is a research goal, not an
assertion or a gate chosen after seeing results.

Primary workloads are packaged Persona and coding (`harness-performance-persona`,
`harness-performance-notebook-reuse`, repeat-launch and captured/concurrent child
histories), plus the actual authored Persona smoke. Scripted inference isolates
substrate costs; a real provider run tests integration and user experience.

Vary at least three sizes of unrelated retained history and logical actors while
holding new source, changed facts, actual dependency demand and output fixed.
Separately vary actual affected dependencies, including legitimate broad
invalidation. Full enumeration may cost O(output); a tiny append should not
rebuild everything merely because unrelated history grew.

The work ledger follows owner boundaries: queue/admission; primary change capture;
world acquisition; requested rows/bytes and physical lease/FD export; GHC dependency
loads/reader/instance work and new-body typecheck; output checking and END;

cleanup. Count changed blocks and selected/backing objects separately. Record
predecessor realization hits, exact cold restores, interpreter epochs, source

Join host/worker clocks with actual operation IDs; use interval unions and explicit
unattributed remainder, never sum overlapping inclusive timers.

worker/descendant RSS/PSS, shared/backing bytes, GC, faults, cgroup pressure and
scratch growth. Verify existing source/original/recovery/input caches as well as
the realization map. Last map-entry removal alone does not prove memory release.

and optional idle-worker affinity remain separate measured follow-ups; a no-go
