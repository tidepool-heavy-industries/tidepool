  endorsement construction is useful.
- Haskell ordinary/World completions form a sum, and pending World dependency
  commitment is checked and consumed through the existing executor owner.
- Q3 correlates item artifacts, captures, signatures and interfaces by keys,

These are meaningful reductions in invalid combinations. Several stop one
boundary before the actual consumer, which is where the remaining work belongs.

## Findings requiring changes

Line references in this review refer to `de12466597`.

### F1. Publication can consume its fallback before settlement succeeds

**Introduced regression; source-confirmed.** In
`exomonad/actor/src/resident_workbench.rs`, `ActorPublicationGuard::{refused,confirmed}`
take `authority` before calling consuming helpers (`2106`, `2143`). A false
result leaves `settled == false` and `authority == None`. Drop (`2185`) now marks
the installation unavailable only when authority is still present.

For `TargetFence`, the helpers (`2278`, `2300`) also drop the external
prerequisite after failed reopen. For `World`, the lower owner's Drop preserves
world unavailability and prerequisite uncertainty, but cannot update the outer
installed state. Do not incorrectly report both variants as losing all custody.

Keep the enum; make failure retain the unresolved obligations or complete the
unavailable/uncertain transitions before disarming Drop. Cover unwind as well
as returned failure. The current bootstrap-only closed-owner test lacks an
external prerequisite and can pass without the explicit unavailable transition.

### F2. Native provenance still mistakes availability for current production

**New N1 boundary defect; source-confirmed paths, new controls not executed.**
`artifact_inventory/native_availability.rs` builds current completion evidence
from all issued availability (`251–277`), including inherited/private rows.
`verified_current_product` (`508–592`) excludes a continuation but treats its
absence as current production. An old private Full row can consequently be
selected as a current root without a current physical product or root choice.

The inverse also exists: `from_pending_selection` does not use actual bound
current-output membership. A real first output with empty own dependency proof
and no prior issued row can be rejected as `CurrentProductNotCompleted`.

The completed product/source owner must provide positive, exact current-origin
membership. Distinguish inherited input, physically bound current output, and
that current output after native issuance. Do not add another caller-populated
inventory or require issued availability before the issuer can run.

### F3. Historical dependency evidence drops the parent's issuing identity

**New N1 representation is incomplete.** `NativeHistoricalDemand.parent` and
`NewProductGroupEdge.parent` carry `NativeGroupKey`, losing the parent's
`ArtifactSelectionId`. Historical verification (`598–660`) can choose the sole
candidate with the matching payload/ordinal without following the authenticated
edge of an exact issued parent. The new-product edge path also keys claims by
payload/ordinal rather than exact parent binding.

Already-issued traversal must retain `NativeGroupBinding`, its recorded outgoing
edge and carrier. A genuinely new parent's inputs come from its actual completed
request selection; they are not a historical edge yet. Two parents with identical
payloads and different exact children must remain independently usable.

The reported six-versus-four group failure is consistent with another identity
loss: current completion recovers children but drops an already-carried own group
binding, then bound admission mints a new parent. Confirm the first failing stage
and preserve exact equality; do not teach the independent oracle to accept six.

### F4. The proposed A1c effective-projection repair changes compiler roles

**Reject that repair as written.** In `declaration_context.rs:784–950`, the
temporary `effective` projection qualifies completed native availability.
`complete_native_entries` includes retained implementations that intentionally
do not have an Original role in `compiler_namespace_row`. Returning `effective`
and adopting it as the semantic compiler projection would promote that custody
into compiler source selection.

The repair must retain the exact demanded native payload/group/carrier without
widening compiler roles. The next observation belongs before and after
`issue_selected_custody` filters `selected` (`artifact_inventory.rs:4840–4919`):
was the exact Core offer never acquired, or acquired and discarded? The current
RecordedRows path does not perform the dependency acquisition used for fresh
PrivateAvailability. Follow the actual completed request evidence through that
owner. The bare canonical-only fixture should still refuse without native bytes.

### F5. The public actor route and service output are not joined

**Open feature work, with a partial migration of the old entry point.**
`begin_private_execution` now requires a published world
(`runtime/session/admission.rs:2913`). `begin_cold_private_execution` (`2942`)
has no production caller and opens the compiler synchronously while holding
mutable session access. Ordinary actor preparation still calls
`snapshot_cell_program`, constructs finite inputs and uses the old parser and
admission (`resident_workbench.rs:8669–8813`).

S1 adds `issue_segment_originals` and physical producer identity, but no
`CheckedWorldCellProgram` executable seal. Expression admission, item successor
adoption and final World publication still refuse missing capabilities. Calling
the cold helper or removing an error branch cannot complete this join.

Assign one engine integrator the complete cold-first-cell → checked output →
execution → private successor → final publication path across these files.
Use the existing compiler-work/source owner outside machine checkout, then
revalidate and publish inside checkout. Delete finite consumers in the same
accepted cutover. Successful lookup must not be an undocumented prerequisite.

### F6. Parse-once removed the lower owner's admission requirement

**New internal bypass surface, not a demonstrated malformed live wire request.**
`CompilerRequest` validates into its private `HeldWorldCellAdmission`, but calls
exported `GhcPipeline.scopedCompileWorldCell` with independent raw arguments.
The latter no longer validates the recipe/plan/slots. Current dispatch validates;
another internal caller can omit that step.

Move the opaque admission into `GhcPipeline` beside its compiler-scope owner.
Validation issues it; compilation requires it and rechecks the live executor
and held world. Delete the raw overload, without reparsing. The current parse
counter test binds a request but never compiles or emits World output.

Q3's grouped-syntax extension also needs source-item and execution-item identities
kept distinct: its current singleton assumption is safe only under the temporary
declaration refusal. Use the existing parser's grouping when removing that refusal.

### F7. Deletion removed off-checkout native preparation, not its obligation

**Introduced routing change; performance impact unmeasured.** The ordinary bind
route now enters `with_compiler_machine`, then
`begin_ready_bind_in_checkout` (`resident_workbench.rs:8987`, `9414`), reaching
`ScopedTargetImage::compile_scoped` during installation (`resident.rs:7230`).
The removed route prepared native code outside checkout.

Keep the old capsule deleted. Put immutable native preparation under the existing
new operation owner, and keep fresh source/scope/item/generation checks at
installation. Preserve progress of independent permitted machine operations,
lost-waiter cleanup, stale-image refusal and no effect replay. B-03 residency and
B-04 codegen reuse do not substitute for those controls.

### F8. Several partial representation changes need their remaining consumers

- **Q6:** `preparedCompilationResult` still exports a raw result containing
  `HscEnv`; Main's World, preview and extraction stages use it. Migrate concrete
  stage operations into the guarded owner, retain output intent, then delete
  the getter. Remove finite consumers with the route rather than adapting them.
- **Q8:** a later `RendererAccess::CloseUnconfirmed` observer is still converted
  to ordinary `Compile(ExtractFailed(...))` (`resident_workbench.rs:8178`).
  The producer's rich error therefore does not survive the slot/waiter boundary.
  Retain typed terminal meaning in the existing slot, including unknown close.
- **Q5/lifecycle:** original A versus target B, Open admission around preview
  bind, SAME custody return and physical receiver cleanup remain open. Descriptive
  labels or transport origin do not establish runtime source authority.
- **Q9:** toolchain's partial wire validation and runtime's decode both remain.
  The new sum still carries broad `InspectionResult` and an optional defining
  receipt where success requires one. Semantic pins differ across public verbs;
  rowFit still browses/solver-checks the entire scope; SourceError can become
  not-found. Preserve both existing validators' checks when consolidating.

### F9. Test setup and test claims conceal the unexecuted join

The residency fixture never enters `ResidentSession::with_source_compiler_transaction`.
Its testing settlement observer is not that transaction. The install rejects it
before any collector measurements. Repair setup through the existing source
owner, retain the independent residency oracle, and port the full service history.

`service_cell_slice` remains ignored with helpers that unconditionally return
errors. Some recorded API gaps are stale: public private-execution and source
transaction wrappers exist. Do not expose private world constructors for the test.
The genuinely missing executable seal/successor/publication must be supplied by
production work.

The Q10 operation observer has no production-history consumer and still names
deleted split-route spans. Its four passes are observer tests, not attribution
of actual World work. The 20 stale / 8 product / 4 unknown classification is a
first-failure triage, not a disposition of later assertions. In particular,
preserve bounded-first/zero-repeat read costs, exact graph roles and the
post-recovery comparisons; do not fix only the first error text.

## Corrected implementation and evidence rules

1. Owner-issued relationships must reach the consumer. An enum whose constructors
   infer the same facts from inventories or labels does not solve that problem.
2. A failed consuming transition must retain its unresolved obligations; a Boolean
   cannot carry them. A closed transport is not proof of successful cleanup.
3. One functional owner closes R1/S1/actor/bootstrap. Bounded leaves may change
   shared functions through reviewed commits; file limits must not prevent the
   assigned production behavior from being delivered.
4. Delete obsolete APIs and move the meaningful controls to their replacement
   owner together. Do not restore finite fallback, private authority factories or
   the deleted split capsule to obtain green tests.
5. Separate compilation, local classification, actual service execution, and
   frozen hosted acceptance. A source-supported counterexample still needs its
   controlled production-path test; an old first failure does not clear later code.
