# One source-admission issuer

S owns this production policy migration. Preserve both finite renderer validation
and World stage progression; they are real consumers, not obsolete alternatives.

Issue one opaque source-admission bundle from validated source receipts, actual
input compiler roles, current products, prior program support and protected
template authority. Expose three distinct typed projections: compiler dependencies,
lexical admissions, and protected template links. Consumers borrow the whole owner;
they cannot pair arbitrary metadata, acquired bytes and permission.

Rename/private home_imports as consumed adjacency. Its keys never establish lexical
roots. Replace the duplicated support classification loops with thin adapters
that bind the actual request/World stage/predecessor and call the common issuer.
world_stage_fragment and source extension consume issued dependencies and lexical
delta rather than deriving roots from adjacency again.

Historical Original bytes without a source claim remain dependency evidence.
Promoting them into lexical/source authority requires the existing explicit
validated selection or prior issued program-source claim. Protected templates
authorize their exact compiler/instance imports, never unrelated authored imports.
Produced type outputs cannot supply source admissions. Keep exact canonical owner,
path/resolution, request/stage and prior-prefix refusals.

Carry the issued owner through source prefixes and output consumers; coordinate
its minimal durable representation with D. Do not add a second snapshot graph.
Typed local failures include owner, requested claim, held classification and
request/stage/restore boundary, with bounded tracing and existing error taxonomy.

First controls: valid dependency additions do not change lexical roots; hidden
dependency acceptance versus unclaimed source-promotion refusal; explicit source
selection and wrong-owner controls; protected Display links remain nonlexical;
finite and World adapters preserve the same classifications; failed admission
does not change prior context and honest continuation remains usable. Then execute
the actual Text/Display history. The latest exact failing owner is still unknown;
do not weaken the guard based on that hypothesis alone.
