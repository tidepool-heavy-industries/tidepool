# Runtime and snapshot consumers

## A: runtime

Consume B's single linked owner. NativeInstantiationPlan becomes a compiled-image
projection, not a second graph resolver. ProgramFacts retains the exact node and
its original NativeSourceCustody/resources, not an incoming whole-target selection.
Export requests derive image, code identity and requirements from one prepared
node. Remove the production route for pairing an arbitrary identity with an image.

Normal dependency occupancy uses (live SourceInstanceDomain, closed CodeId), after
authorization and source-head admission. Same nominal code/dependencies in one
domain shares dependency state; independent domains remain generative. Invocation
targets are always fresh. Parcel import preserves exact existing instances and
must not enter global code deduplication or implicitly publish dependency occupancy.
Captured roots keep their actual instances and original owners.

Resolve retained requirements through the actual live scope/type/generation owner.
Keep transactional install, stale permits, root detachment and collector liveness.
The target graph exists before END/execution. Existing successful settlement
advances the executed World frontier; preparation or failed/cancelled/stale work
cannot. Do not put GroupInstanceId or an installed graph into World. Delete the
old local HOME/PACKAGE graph reconstruction and obsolete native sibling APIs.

## D: persistence

Replace NativeCompletionSnapshotFacts expanded rows with references to B's SAME
component owner. Encode/hash each immutable component once; changing roots writes
changed reference paths through existing HAMTs/store transactions. No new durable
prefix facility: existing prefixes/heads borrow references; persist only the
already-durable context state.

ContextDescriptor 7 -> 8. Delete the old native-completion codec/domain; introduce
versioned linked-component encoding and a distinct hash domain. Keep unrelated
SelectionDescriptor, PublicationNativeDescriptor and Surface versions unless their
actual layouts change. No blanket compiler-wire bump without a changed contract.
Old compiler contexts refuse explicitly; no compatibility path. Preserve files,
memory, logs, source/name history and loss markers.

Restore decoded data by acquiring/authenticating actual bodies and grants, then
using the same linked-owner constructor against exact references. Validate canonical
member order, maximal SCCs, intercomponent acyclicity, every ordered edge and
content commitment. Never relink by symbol or inventory lookup. Regain sharing.
Decoded code IDs cannot restore runtime handles, machine instances or effects.

Keep Surface and BindingScopeSnapshot physical observations: they are legitimate
staleness evidence, not restorable authority. Preserve publication transactions,
rollback, source/version fences and existing missing-versus-inaccessible errors.
No storage-engine rewrite or generic caching framework.
