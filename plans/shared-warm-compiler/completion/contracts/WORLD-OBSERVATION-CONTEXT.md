# World observation context

The existing compiler World lexical product retains an optional protected observation scaffold. It is descriptive compiler input, never a runtime grant. Module-only Worlds remain valid and refuse row-dependent questions with a typed unsupported result. Queries do not fall back to the finite inspection batch.

## Issuing owner and lifetime

The common `ActorWorkbenchSource::for_workbench` source producer issues the scaffold from the actual admitted actor context and current `RequestWorkbenchScope`. The same producer supplies the cell recipe and observation declarations. It retains the original static source preamble, ordered static imports, effect alias/type imports and actual request/input TYPE helper declarations. It excludes cell bodies, an arbitrary previous cell recipe, handler executables, runtime input values, request-ID VALUE right-hand sides, and the runtime `me`/`currentModel` right-hand sides. Do not recover declarations by stripping arbitrary Haskell text.

The closed profiles are Workbench and HostCarrier. A HostCarrier's pure row must never silently replace a Workbench row. Request signature slots use the existing native checked-signature producer; display strings are not type evidence. Observation helpers have signatures and inert bindings suitable only for private compiler observation. They are not evaluated or published.

The scaffold is retained once in `CompilerWorldOpenInputs`' existing lexical surface, then decoded once into Haskell `WorldInputFacts` owned by `HeldCompilerWorld`. Mutable GHC realization state stays in the existing `WorldPreparedModules` owner. Per-query requests contain only the held World identity/realization and task operands. `TcGblEnv`, `HscEnv`, runtime values and repeated full context snapshots do not cross this boundary.

## Identity and sharing

Changed compiler semantics (selected imports, row, protected declarations, nominal reply/progress/input types or profile) changes the lexical fact and logical World. Different request IDs with identical compiler semantics may share the same logical World. Exact request identity remains in the actual actor pin, source admission and settlement revalidation; it is not another compiler fact field or an executable literal in the scaffold. The source capture retains a typed `InspectionActorObservation` containing the original principal, concrete effects type, optional request observation identity and optional `currentModel` type. The runtime identity owner frames this with its existing source/import/binding observations. A selected model value with the same helper type does not change this compiler observation.

The World owner admits all actual original TYPE contexts before comparing lexical scaffold shapes. One primary-and-lexical derivation emits one successor from the original held predecessor. A scaffold-only change derives a new lexical root/product while sharing primary context, primary associations, source capture, binding rows and their immutable custody. It must not recapture source files or enumerate all retained values. Existing World acquisition/restoration and source/authentication/END checks remain authoritative. An equal scaffold returns the same World reference. A changed scaffold clears its checked-cell position; it cannot inherit another logical World's item certificate or ordinal. The actual actor scaffold must be attached before plan/reserve and inherited by item successors; do not install a changed observational World over an active checked prefix.

## Paired lexical record

`TPCWLEX2` is an array of four values:

1. `TPCWLEX2` tag.
2. Existing ordered current import specifications.
3. Existing selected declaration facade record or null.
4. Null for module-only, otherwise `[profile, protectedFragment, staticImportSpecs, requestTypes]`.

Profile is 0 for Workbench or 1 for HostCarrier; other values fail closed. `protectedFragment` is one exact source fragment, not independent editable preamble/row/helper strings. `staticImportSpecs` preserves order using the existing import-spec owner. `requestTypes` is null or `[request, input]`: request is null or `[helperRecipeTag, RequestTypeSignatures]`; input is null or the existing CheckedSignature CBOR value. Tags and nested values use the existing checked-signature codecs (`none` / `actor-reply`). Actual leased HostBindingPrototype/checked-carrier type ownership supplies input, never BoundBinder text. Haskell uses `rewriteRequestTypes` with those exact native Types and checks the existing generated signature slot counts. Legacy lexical tags and malformed/unknown variants fail closed. The existing product root slot remains unchanged; its CID commits the new lexical body.

## Observation and acceptance

The Haskell World owner hydrates the exact selected lexical facade and validates exports before deriving private observation context. Keyed rowFit resolves one candidate in that actual context (preserving aliases/reexports, namespace, ambiguity and exact generation), then uses the existing GHC row solver. Expressions and type search use the same held context. Private probes do not advance a cell prefix, publish a successor, install names or grant runtime execution.

Acceptance requires actual current-scope positives through the production effect loop, wrong-row and changed-request-type negatives, stale settlement and module-only refusal, and a no-publication assertion. Same-semantic request-ID changes must preserve the logical World while changing the request-bound actor observation pin. Allocation-only reservations and transport relocation preserve semantic pins. Local codec/shape tests are not all-five or installed-Persona acceptance.

## Input and private invocation custody

Before private admission, the actual checked carrier/prototype supplies input TYPE metadata without mounting its runtime value. A cold JSON carrier is prepared and settled under its existing source owner; its retained prototype supplies the later private mount. Activation input exposes its original prototype directly and retains its actual `sessionInput` binding identity, distinct from the JSON `input` helper. Read-only access exposes existing signature data, not fresh permission. RequestTypeSignatures supplies reply/progress types only. Generated input slots use the separate retained native CheckedSignature. No rendered input type or runtime mounted input value completes the scaffold. Q owns the Rust fact/capture, scoped operand codec, GHC observation producer and actor route; H reviews the shared checking stage and owns the paired lexical decoder. Source compilation and local controls do not establish hosted semantic acceptance.


## Closed query operation and runtime settlement

Worker v27 pairs the field-58 closed World question with PREP5 stage-local runtime references. Public-module info/type retain their body-v1 answer. Scoped info/type, keyed availability, expression type and bounded-output type search use TPWQ0002 body v2 `[2, worldRoot, provenance, questionEcho, outcome]`. The lower decoder checks the exact root, full scope pin, operands, result kind and output cap once. The toolchain privately pairs decoded data with the actual admitted World; runtime `PreparedInspectionWorld<A>` and `CompletedInspectionWorld<A>` retain the existing exact source/target, compiler-origin END and cancellation owners. A response is never assigned a different pin after decoding.

The private result-indexed World source operation shares actual dependency HPT preparation and target checking with cells. Its observation branch fixes CheckedEnvironment, runs the existing introspection/row solver before the transient checked environment leaves scope, and returns encoded data. It neither certifies a cell nor emits/evaluates native code. Only immutable dependency products enter the existing held owner. The generated module identity is stable for the logical World. Type-search hydrates candidate TYPE interfaces deliberately; its output cap does not limit that work.

Raw expression/type operands cannot contribute additional module declarations. The same sealed parsed module proves the exact generated suffix declaration shapes and physical parser-buffer boundary, including Unicode prefixes and authored LINE remapping. The same resolved native slot product annotates demand renaming and final checking after the actual selected HPT is installed. GHC source failures remain compiler diagnostics, never unknown-name/empty-search answers.

The actual request Workbench issues `CapturedObservationScaffold` as one inseparable compiler scaffold and private invocation observation. Runner admission consumes the pair; it cannot reconstruct a request from actor placement. `ExecutionPrivateScope` retains exact actor/request/effect/model facts and request/projection owner references. Scoped queries check their current Workbench against those facts before using the original held scaffold, preserving activation `sessionInput` TYPE custody. A module-only/None admission remains valid for public-module queries and runtime scope snapshots but lacks scoped compiler context. Changed request/row/owner context is refused; it must not refresh an active prefix or manufacture input type evidence.

The actor compiler-backed effect handlers use this World operation directly. CurrentScopeView remains its entry snapshot; scopeBindings remains runtime enumeration. The old browse/filter rowFit plan and finite current-scope effect inspection route are deleted. A separate synchronous `:bindings` status type-display fallback still uses finite inspection and remains a distinct follow-up, not acceptance for these verbs. Canonical identifier receiving defense for aliases/imported/protected names and actual hosted all-five execution remain required qualification work.
