pairing, P2 Rust decoding/selection, P3 independent controls. Use the current
campaign base and [CONTRACTS](CONTRACTS.md), not the superseded v12 supplement.

all consume the exact package environment their real producer selected.
Adjacent questions: unnecessary whole-HOME projection; unscoped/alternate APIs;
whether tests assert exact edges rather than owner sets.

pairing; CompilerProducts stage/item writers and PreparedPackageOutputs;

actual group is projected, and close only its real package demand through the
existing worklist. Required unsupported work must still refuse; unrelated
unemitted failures must not be introduced.

Delete resolveHomeRoots' request-wide unionOwners/rematching. Multiple targets
may use a shared HOME issuer only if they actually share its issuance, not
because separately projected roots can be made equal by graph quotienting.

and identical-row rejection. Keep envelope byte deduplication. Equal row content

as useful reproducibility, not as a substitute for selection identity.

## P3: tests that distinguish the relationship

P3 owns maintained test changes and works from actual production issuers.
Do not hand-assemble certified authority. A raw receipt mutation is appropriate
for testing refusal after acquiring a real valid baseline.

Required early controls:
1. A tiny World declaration/expression with actual package globals; execute a
   later cell using it. Observe that item roots match the paired producer even
   after scaffold renaming. Missing/crossed-item roots must refuse.
2. Two ordinary results use the same fresh HOME byList/byText groups and package
   imports. compile_invocation carries first completion into the second; assert
   exact repeated binding/edges and execute the result. Reverse target order.
3. Each HOME ordinal's exact roots: assert the actual issued ordinal and exported
   binder, its ordered imports, and absence of the other ordinal's root.
4. Add an unused competing same-interface product: the selected target and
   exact transitive child remain unchanged. Assert a competitor really exists.
5. Equal payload/different exact child histories across independent projections:
   assert equality of payload, inequality of edges, each exact selection.
   Keep same-scope conflicting-plan refusal where that is the current contract.
6. Unrelated unsupported HOME group does not become a new mandatory projection;
   a genuinely demanded unsupported group still refuses. Establish that the
   unused group survives GHC preparation and fails at the unwanted projection;
   a group optimized away by GHC does not establish this premise. If only a
   raw-projection-input component control can expose it, label that scope
   honestly and pair it with a real successful producer history.
7. Reopen selected graphs after deleting only test-owned disposable producer
   outputs. Exercise actual cold/retained acquisition, not just singleton issue.
8. Distinct occurrence IDs may carry byte-identical row content; repeated
   ordered roots/edges preserve multiplicity and share immutable payload
   custody. Duplicate IDs and out-of-range IDs refuse. Distinguish schema-level
   controls from authenticated acquisition; do not invent authority for a
   positive receipt test. Keep the old physical-global dedup smoke claim honest.

Before implementing controls 4/5, P3 must identify a real producer history and
report its parent/child coordinates, equal payload digest and first differing
exact edge. The retained same-seal products have zero imports and cannot supply
the different-child premise. Different module reachability alone also does not
establish it. If no current issuer produces the required premise, retain the
discovery evidence and mark that guarantee unqualified for P/R-P review; do not
weaken the assertion or manufacture certified authority. Continue the independent
item/repeated-Fresh/ordinal controls while resolving that construction.

Fix or rename the old nonempty/owner-union tests. Keep useful ordinary smoke
coverage but stop counting it as World-item or adversarial-history evidence.
Replace silent depth-eight history flattening with exact small-edge assertions,
or a finite ordered graph observation with cycle handling if actually reused.
Assert cardinality before zipping.

Refusal controls include missing/out-of-range/cross-output links, import count,
wrong owner/interface/version, producer/profile, export/signature/
representation/evaluatedness. Use the existing typed refusal categories.
Do not use .is_err() where a specific wrong selection would fail differently.
