## The decision

Finish two coherent joins, then qualify them together:

1. **A private execution has immutable birth authority and an owner-issued
   current preparation state.** Birth state is the baseline for three-way
   publication. New authored work uses the current state. Host acceptance,
   checked completion, retirement and freeze must preserve that distinction.
2. **An exact native selection carries its issuance, imports and custody through
   every consumer.** Package completion and source membership must use the same
   selected row. Narrowing may change compiler namespace roles without losing
   the selected native payloads it still requires.

These joins address the observed failures and adjacent unfinished migrations.
They require neither another compiler architecture nor a new generic lifecycle
framework. Reuse the session checkout, compiler World, certified group owner,
source-selection proof and package graph owner already present.

## G2 and G3 cutoff

The existing [G2 contract](../g2-completion.md) remains controlling. After the
joined ordinary histories pass, build and freeze one matched bundle. Verify the
actual Persona spec, declared tools and rendered initial memory; run bounded
DeepSeek multi-turn smoke with retained values, discovery and default reload.
Preserve authored files/memory and launch fresh conversation state. No stale

Full force/fork/callback/worker-loss/process-recovery matrices and full M1–M3 are
G3. Ordinary activation and disposal-safe compiler reacquisition are not optional
G3 deferrals. Unsupported G3 operations must explicitly refuse at G2. A recovered
compiler World is not proof that a dead process's heap values can be restored.

V can prepare G3 test/ownership mapping in parallel, but no new general framework,
speculative cache, provider feature or unrelated optimization blocks G2. G3 also
requires all recorded failures dispositioned, map reconciliation, packaged timing
evidence and reviewed integration/release/main convergence with explicit remote
OID checks. G2 does not imply the whole campaign is finished.

## Stop the patch spiral

Do not relax a stale guard until its owner and allowed transition are named.
Do not derive progress from equal final states, choose a token from equal payloads,
or turn unavailable source custody into an unexplained `Unknown` success. Preserve
the selected reason in typed outcomes and the issuing evidence across the next
consumer. Delete the old route once the new production caller is migrated.

If a worker meets a real contradiction, send the smallest production history,
the two conflicting contracts and a recommendation. Finish independent work while
the supervisor resolves it. A new assertion, a different error frontier or a
component pass is not by itself an architecture decision or joined acceptance.

The bounded unknowns are explicit: H must confirm the earlier custody-dropping
constructor while implementing the reproduced refusal; P must establish the
real transitive HOME premise through emitted code; N must demonstrate original
input A in recipient B and all legitimate parked/multi-item transitions. A real
nested authored-program workflow, beyond the known HostCarrier path, needs its
own captured parent/child contract before imposing a blanket busy rule. These
are targeted discriminators, not invitations to start another broad rewrite.
