## Objective

Make the full resident compiler path represent its actual domain: decoded data,
certified facts, custody, selected compiler inputs, executable permissions,
live runtime bindings, successful execution, publication and recovery.
Construct coupled entities together. A consumer receives the issuing owner's
result, not independent pieces and an instruction to validate their correlation.

Keep the warm GHC service, existing exact graphs, code interner, persistent
structures, session owner, compiler settlement boundary and actor scheduler.
This is a coordinated replacement of invalid assembly routes, not a generic
capability/typestate framework.

## Binding contracts and delivery

Read [CONTRACTS.md](CONTRACTS.md), then the owning group plan:
[facts/context](FACTS.md), [compiler service](COMPILER.md),
[runtime/publication](RUNTIME.md), [validation](VALIDATION.md).
[STATE.md](STATE.md) records ownership and exact candidates.
[CLOSEOUT.md](CLOSEOUT.md) owns the accepted final selected-row implementation,
joined runtime cleanup and G2 qualification sequence.

Root owns shared architectural decisions, cross-group integration, exact-source
validation pins, map updates and final aesthetic review. Group owners implement
their core parcel and consolidate related children; they are not status relays.
Workers send their parent and root events at contract changes, blockers,
compilation, review-ready candidates and completion. Do not wait on a parent
silently; finish an independent frontier or provide the smallest actionable
handoff. Preserve source/WIP and report exact commit ancestry.

Each assignment has one primary invariant and adjacent checks for unnecessary
work, surviving alternate routes, and test-oracle quality. Done requires
replacement API deletion, affected production/test compilation, focused executed
evidence, and joined acceptance. Source-only is an explicit intermediate status.

## Sequence

1. Freeze constructor ownership and narrow shared signatures. Facts/context
   and compiler-service frontiers start independently.
2. Converge SOURCE/native queries and admitted stages before runtime consumers;
   codecs depend on the selected-row model; publication depends on completed
   runtime frontiers.
3. Integrate coherent subsets, compile joined consumers early, run the smallest
   production history, then expand tests. No mass final uncompiled merge.
4. Remove obsolete APIs, fixture construction paths, comments and build entries;
   perform independent joined/aesthetic review.
5. Run maintained G2 cohorts and freeze one matched bundle. Verify Persona spec,
   tools and initial memory, then fresh DeepSeek chat with authored files kept.
   G3 lifecycle/fork/recovery qualification follows separately.

Current scratch is 113 GiB free; retain 100 GiB plus expected growth. Use the
existing warm integration outputs first, not another cold checkout expansion.
All builds use admitted pinned local-only commands; no worker may bypass a
resource refusal. Source-only branches need no new build mount until admitted.
