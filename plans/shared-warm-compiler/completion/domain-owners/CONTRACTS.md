# Shared domain contracts

These are semantic and construction contracts. Routine naming adjustments may
be agreed between owners; changing authority, phase or lifetime requires root
review before implementation. Private constructors are mandatory. Do not expose
a test factory or compatibility setter for removed assembly.

## Certified facts and acquired inputs

A private `OriginalDraft` becomes a complete certified original through the
existing consuming certifier. Complete facts contain mandatory canonical/native
facts; replay/source-admission evidence is a separate concept and can legitimately
be absent. Inventory cannot complete a draft.

`AcquiredOriginal` retains `Arc<OriginalFacts>`, actual input transport custody,
and closed fresh/recovered admission provenance. Fresh evidence is the existing
checked source-admission token, not a digest/UUID fabricated from equal bytes.
Derived OriginalNativeWitness allocation is not executable permission.
Immutable interning may replace only facts, never fresh admission, actual
catalog/arena lifetime, or a selected native contribution.

Actual permission continues to use existing exact NativeOfferContribution,
AcquiredHomeCodeGrant and acquired package receipt occurrences. Equal facts or
code neither merge independent partial grants nor select a replacement issuer.
Remove retain_acquisitions reassociation through broad ArtifactId maps after
callers carry actual selected owners. Merely replacing pointer checks with
deep equality is not the repair.

## One selected compiler namespace

Live selected rows are one persistent map, closed as InterfaceOnly or Original.
An Original selection privately owns its exact canonical relationship and
AcquiredOriginal; no public canonical/original tuple constructor. Its provenance
is Reusable or Published with a checked immutable birth relation. Published birth
retains the actual pre-endorsement support (a DAG, never the receiving current
projection). Current SOURCE/lexical adjacency remains a distinct relation.

A private whole-row choice selects Receiving or Incoming; consumers clone the
chosen row, not stitch parts or reconstruct issuer from equality.
Native choices distinguish unissued, issued-empty and an exact selected
contribution. Private availability may exist without a compiler Original role.

`AssemblyRoleView` and `AdmittedCompilerRoles` are distinct borrowed interfaces.
Only actual selected support/context issues the latter. Pure render/comparison
helpers may share authority-free row facts; authority APIs cannot accept that
common surface. No second owning map. Derived transport/encoding indexes are
private and updated by the same owner; they never issue selection.

## Compiler requests, stages and dependency evidence

Raw request records exist only at decoding. Pure full-shape admission produces
operation-specific variants before allocating executors, changing RTS limits,
reading source or writing harness copies.

SOURCE queries/replies and native demand/replies are distinct types. SOURCE
replies cannot carry package acquisition. The transport channel may be shared;
its encoder derives tags from variants. Runtime identities on the wire remain
checked at ingress.

One pending request ledger contains per-stage SOURCE observations and native
selection. Consuming finish returns Result, not a completion plus optional error.
Bind to the actual emitted-stage table, rejecting every orphan key, SOURCE and
native alike. Explicit empty stage evidence is issued only there.

At stage sealing, batch-authenticate selected terminal references by exact use.
Retain full original-use, demander binding+ordinal, global slot, retained binding,
symbol and generation. Traverse each relevant use once. Store validated rows
under a SealedStageDependencies owner; handles reference owner+index. Rows do
not hold a backreference to the enclosing stage. No global cache/new graph.

Link prior inputs to actual producer output evidence before constructing admitted
stages. Base, operand and prior-produced inputs are distinct variants with their
own parsed seal types; a Vec of bytes is not a universal identity.
A cursor opens the next stage; only branch-specific successful sealing advances.
SOURCE-only advancement can retain the earlier native prefix: those histories
are distinct and must not be collapsed into a false all-or-nothing phase.

## Interface/environment lifetime

Captured inputs carry authenticated bytes, identity, role and actual NameCache
association. Hydration issues selected HPT plus environment together. Lexical
installation takes that owner, validated SOURCE/graph evidence and a cycle
backing scope; it materializes and registers demanded files internally.
No free BackedInterface can claim installation before HPT hydration.

TYPE alone does not authorize lexical SOURCE or filesystem access. Preserve
source-root observation before installed Finder entries can obscure it.
Only demanded interfaces become physical files. Cycle files die with the cycle;
actual captured HMI/byte owners survive independently. Keep existing World
source/product backing where it is genuinely needed.

CompilerUniverse holds fixed boot/package context and actual completed version
owners, not the last operation's mutable HscEnv. Attempts select exact completed
nodes and preserve real lazy HMI knots and required SOURCE backedges.
Helpers cannot publish transient Finder/HOME state into the universe.
Thread, executor, NameCache, World binding, interpreter and cleanup checks remain
dynamic at the owning transition; do not replace GHC's monad with a new framework.

## Runtime and publication

Keep PreparedRuntimeCell -> actual CompilerTransactionSettled ->
SettledCellProgram. Existing runtime/session owner issues one scoped resolved
input set; retain actual values/handles/rows/leases and derive import projections.
Fold the provisional BoundRetainedInputs adapter into that owner.

Reserve/open/run/park/complete/fail are closed transitions with affine tickets.
The ticket carries exact item, predecessor and capture plan. A successful
CapturedCheckedValues owner installs binding, checked row and provenance together
and alone advances the committed prefix. Prior-stage outputs become live only
after their actual producer succeeds.

On session re-entry, check mutable owner epoch, scope/source revocation, machine
incarnation, continuation and public CAS baseline. Immutable compiler membership
and checked fact compatibility are authenticated once, then carried.

FrozenWorldExecution is issued from a completed private frontier, with mandatory
World evidence and actual private lease. Declaration/binding publication is a
closed payload distinction. Retry replaces only public merge baseline, never
private effects, winners or historical acquisition. Recovery compiler evidence
cannot become a live value or a completed execution.

## Encoding, errors and compatibility

Context10 decodes recorded rows only, then existing authentication constructs
live support. No live Deserialize/generic Eq or mixed Recorded/Acquired authority.
Context9 explicitly refuses; old evidence and authored memory/files are preserved.
PREP6/internal wire layouts need no change solely for a stronger internal type;
change matched versions together only when authenticated meaning/layout changes.

Each transition owns a typed failure cause and original underlying error.
Malformed records, incompatible facts, missing permission, live revocation,
wrong phase and CAS conflict remain distinguishable. No string-driven control.
Normal structured tracing stays bounded/optional and retains request/stage/owner
coordinates without creating a second event framework.
