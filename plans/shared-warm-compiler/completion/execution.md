This file refines [next-wave.md](next-wave.md) and the [cell boundary](contracts/CELL-PREPARATION-BOUNDARY.md).

## Owners and folding

Root supplies and reviews the difficult owner transitions. Three Sol area owners
receive implementation leaves and fold them into their area branches; root folds
reviewed areas into `integration/compiler-query-warm-final`. Leaves use isolated
checkouts, read the nearest contributor rules and compile actual consumers.
No main promotion or Persona deployment follows from a compiling scaffold.

| Assignment | Receiving owner | Initial responsibility |
| --- | --- | --- |
| N0 | root → native leaf → engine | Positive current-product accessor and its real resolver consumer |
| N1 | native leaf → engine | Exact issued/new-current result, both planners, custody, A1c and birth/reopen |
| H | Haskell leaf → engine | Scope-owned admitted operation, guarded stages and correlated output |
| V | engine integrator, with root review | Cold bootstrap, executable seal, item successor, atomic publication, sole route |
| P/L | lifecycle integrator | Armed publication, terminal diagnostics, original A/target B, retirement/recovery |

| Q | query leaf → verification | One typed answer admission, semantic pin, precise failures and all-five composition |
| D | request-flow leaf → root | Carry parsed daemon request; preserve wire and correlation; measure host preparation |

Start with at most twelve active nodes. Context-loaded auditors own corresponding
repairs; another worker reviews each exact candidate. A child reports proposal,
blocked, review-ready and settled transitions to its parent. Area owners continue
the next unblocked assignment and consolidate accepted work before handing off.
Shared signatures are receiving commits, not independently invented interfaces.
No native Codex goal loop and no periodic busy polling.

## Root/native foundation

`CertifiedSourceSelection` already records NewProduct/Input origin, pending/bound
original identity and request input ownership. Issue a private current-product
borrow from those facts; do not derive membership from available originals,
pending dependency proofs or issued availability. Pending physical identity is a
refusal, not absence. Authenticated Cached output is not excluded by its label.

The borrow captures its own selection and resolves through that selection's
input owner. Do not accept a second selection beside it: ordinary Rust lifetimes
do not brand requests. The native resolver has two real outcomes: exact issued
support to reuse, or a positively completed unissued current group to plan.
Existing support owners retain exact snapshot and physical payload custody.

Use the existing exact/current planning distinction in both bound admission and
selected-custody admission. New same-cohort dependencies may remain planned
`NewGroup` targets until the complete demanded cohort is issued; requiring prior
bindings for every such dependency creates an issuance cycle.

Historical traversal reads the exact parent node, labeled edge, exact child and
recorded carrier from its supporting owner. Keep request-choice maps separate
from multi-issuer historical custody. Never flatten an exact target to a logical
key and recover it from a global preferred map in the second planner.

Delete `NativeProductCompletions`, deferred consumable errors, the optional-binding
provenance matrix, error-driven historical fallback and ambient-interned custody
lookup. Semantic interning remains valid for semantic facts. Retain exact payloads
through the selected support owner, including equal semantic bytes acquired under
different physical owners.

A1c must acquire demanded support before filtering without adopting the temporary
`effective` compiler projection. Retained Core stays InterfaceOnly when selected
that way. Trace the first missing support and four-versus-six divergence; absent
producer evidence requires producer repair, never a latest-version reconstruction.

## Haskell and executable service boundary

The scope owner issues one opaque preparation containing parsed plan, held
identity, executor, grant and scope association. Compile and dependency commitment
consume it without independently supplied authority. Keep live checks inside the
existing guarded operation; do not call a Ready-only guard after entering Running.
Pending dependency commitment retains its issuing executor and remains one-shot.

Migrate the actual World, preview and extraction consumers before removing the
unrestricted prepared-result accessor. Return immutable stage observations instead
of exposing HscEnv. Reuse parser execution grouping, retaining source ordinals in
each correlated execution item. Authenticate one complete output record and move
it downstream; raw immutable evidence need not imply a duplicate decoded tree.

V owns the complete joined path across crate boundaries:

1. Capture real public/source base, original A and receiving B under checkout.
2. Acquire the world outside checkout under the existing compiler-work owner;
   cold first use does not require prior introspection.
3. Plan, reserve and prepare with the same source-bound runtime preparation.
4. Authenticate the same captured output through existing product/item issuers.
5. Match END/origin/cancellation before sealing executable items.
6. Prepare native state outside checkout; freshly revalidate and install the
   coupled image, metadata and item.
7. Adopt each successful item's own successor and actual runtime delta.
8. Publish the final post-removal result atomically through the existing owner.

No synthetic ExactCompilationRequest, broad baseline census, second certifier,
new evaluator or cross-crate trusted-value constructor. Runtime owns execution
authority; compiler source descriptions and transport identity cannot grant it.
Original A and receiving B may have identical source descriptions, or share a
source lease. Keep their labeled descriptions authenticated, and check the actual
transaction, target lease and current gates in runtime admission. Descriptive
inequality is not an authority check.
Missing runtime capabilities remain explicit refusals until their actual owners
issue them. Remove the finite resident route when the joined replacement lands,
including bootstrap, renderer, recovery and tests. Declared batch build actions
remain distinct real consumers.

### Lexical state and item prefixes

The logical World must retain authored lexical state, not infer it from module
dependency edges. Cold acquisition captures ordered normalized `SourceImports`
and the selected declaration facade's exact interface and exports from the
existing accepted-join or recovery owner. Authenticate the facade against the
same primary-context selection. Use an explicit absent declaration; ambient
custody cannot fill it. Adding this required semantic root warrants the planned
World format revision and explicit rejection of incomplete older products.

Haskell owns import interpretation and protected-preamble shadowing. Preserve
qualified, hiding and empty imports. The protected static preamble remains a
recipe input, while current binding heads come from the existing binding root;
do not introduce another all-values inventory or reconstruct finite turn imports.

Each item carries its own checked lexical, interface and native prefix alongside
its output. Whole-cell typechecking may inspect later declarations, but that
does not publish later bindings or imports into an earlier item's execution
context. Never seal every item against the final completed context. Successful
runtime settlement supplies that item's actual delta; successor acquisition
names its exact predecessor and authenticated prefix, not the latest namespace.

The engine receives a native-assembly leaf owning the existing `artifacts` and
checked-item assembly. Reuse captured value-interface certification, original
product issuance and native preparation. A shared internal issuer is preferable
to copying the finite continuation machinery. If batch and World plan forms
remain at a shared boundary, expose one exhaustive borrowed plan sum rather than
two independent optional accessors. The resident caller must have one route.

## Publication and lifecycle

Keep authority armed through settlement; helpers borrow it. Track Held versus
ReopenAttempted fence state before consuming a fence. Disarm only on actual
settlement. Typed failures retain the original operation outcome and independent
cleanup/publication obligations.

Unavailable recording is idempotent. Nested fallback must not replace a retained
uncertainty fence with None; retain prerequisite uncertainty once. Preserve exact
attempt comparison and installed-state marking even when lower world selection
has changed. Source A/B, gate-only revocation, preview Open admission, late cleanup
and physical release remain separate controls.

Reserve the prepared generation and its publication guard together in one affine
owner; publishing consumes that owner rather than accepting an independently
supplied candidate and guard. Preserve observed body completion separately from
an outer checkout, task-join or owner failure. A sampled publication phase does
not prove that an unobserved body stopped without committing. Both the primary
failure and the resulting uncertainty must reach the ordinary reload consumer.

Later renderer observers receive the same typed terminal meaning, including
unconfirmed close and producer loss. Retired state cannot launch another producer.
Keep immutable independent snapshots usable. Default reload reports blockers;
force drains only the captured actual set and never silently restarts effects.

## Query and bounded performance receiving work

Q moves full response decoding/envelope checks to the existing lower response
owner, keeps precise answer variants and owner-issued runtime view pins, and
preserves cancellation, absence, compile failure, stale view and owner loss.
Scope comparison and continuation resume occur in one checkout. Row-fit uses
the relevant keyed candidate through the existing GHC solver.

D parses once at daemon ingress and carries ExtractRequest through grant,
mode, correlation and product placement, encoding at worker transport. Preserve
the versioned worker protocol and Haskell validation. Correlation still normalizes
only ExecutionGrant and retains original cwd/field order; actual emitted evidence
retains admitted grant and placed paths. Record bounded decode/encode/correlation
work, including time before the current physical-request span.

After the correctness join, bounded follow-ups may remove an immediate duplicate
probe within one held operation, charge cold materialization before allocation,
serialize borrowed blocks without a second Value tree, and index exact row/image
matching once per acquisition. No new persistent caches. Distinguish cold costs,
live query costs and dormant service-cell costs until the latter is joined.

## Evidence and deletion gates

Scaffolds compile with real consumers. TODO comments name an assignment, required
owner transition, failure behavior and control; they never implement success by
empty collections, fabricate authority or introduce executable `todo!()` paths.

First prove a cold actual actor Haskell call followed by a second cell reading its
binding. Assert real values and operation/world/worker/output identities. Extend
to declarations, explicit/empty imports, expressions, mixed cells, pattern binds
and source-defined retained types; late type failure runs no early effect.

Native controls cover current leaf/no self-proof, inherited private refusal,
explicit empty choice, own-binding reuse, independent equal-payload parents,
parent/child/carrier substitutions, same-cohort dependencies, selected physical
custody, A1c next-request and cold recovery.

Publication controls use an actual external prerequisite, both authority forms,
owner loss/barriers/unwind, repeated fallback, source revocation and uncertain END.
Crossed preflight refusal does not consume the rightful owner's item; a started
item never replays. Residency enters real source admission and preserves its
independent collection bound. Operation oracles observe a real joined history.

Use existing test runners and property infrastructure, reusable immutable
compiled fixtures and fresh mutable machines/issuance. No authority factories.
Run beyond first failures in the 32-case ledger. Close obsolete tests only with
named surviving-contract coverage. Record compile and execution separately.

G2/G3 in plan.md remain the release gates. Freeze a matched early Persona bundle
after ordinary service workflows and failure controls pass; final qualification
adds the full lifecycle matrix, affected suites/fixtures and bundle-owned M1–M3.
Update the engine map from actual consumers and measured work. Push accepted
integration checkpoints; reconcile public main only after joined qualification.
