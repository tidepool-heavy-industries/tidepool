**Goal.** Make the issuer of compiler selection retain the persistent exact selected input root, its immutable role/body choices and exact required edges. Extend/narrow that owner directly instead of resolving the whole retained inventory on every request. Selection reads should reuse issued facts without re-deriving them. Dormant custody must remain available without becoming optional roots. Deliver the minimal typed internal contract needed by delta admission and publication; conceptual names here are not instructions to introduce another registry.

Primary review question: does the issuer carry the correct exact selection without reconstructing it from custody? Adjacent checks: do equal payloads with different issuer bindings remain distinct, and does repeated selected-input observation avoid work proportional to unrelated history?

**Wave D — Review, repair and hand off.** Run generated histories through production issuers and their consumers: independent equal cached-owner/unequal certificate acquisition; equal canonical bytes/different scoped bindings; canonical-only historical dependency allowed versus explicit Original/Full qualification refused; no Original namespace entry but exact group carrier retained; private root H permitted for A but not B; optional-root replacement with retained old values. A cold constructor may traverse all initial facts; repeat selected reads and one-role changes against growing unrelated history and count construction/owner/edge visits, not pointer equality alone.

Remove superseded selected-owner resolution and duplicate optional-seed filters from production callers. Keep any full recomputation only as an explicit test oracle or genuinely cold admission path with recorded scope. Do not leave a compatibility path that rebuilds authority when the issued owner is missing. Missing/inaccessible/authentication failures are refusals, not cache misses permitting another issuer.

**Evidence and refusal gates.** In implementation, use admitted pinned builds, discover exact targets and run `swarm-build just test-lib tidepool-toolchain --exact FULL_NAME --expected-count 1` for focused controls; list real names and counts for added cases. Stop/escalate when a required historical edge changes without an explicit world transition, when a success arises only by relaxing a conflict validator, when semantics depend on a shared production oracle, or when the output contract would overlap sibling ownership. Acceptance is a reviewed issuing contract and executed front-door controls, not yet whole-area performance acceptance.
