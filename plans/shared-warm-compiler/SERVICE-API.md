alias, shadow, removal, inherited-parent change, source/catalog replacement,

is a CAS against the original issuer-owned base and never publishes bindings.

retries via fallback; only an owner-issued proof of nonacceptance can authorize
a different path. Missing acceleration is not corruption; inaccessible source is not
absence. Unsupported/fallback reasons use typed control flow and are counted.
The first slice does not claim incremental cell/successor publication. That is
the next dependent wave through the existing atomic declaration/value owner.
