# Owned compiler artifacts and complete renderer reuse

## Baseline and delivery contract

Implement from accepted `2a174f86590e0b3c560f1c018f35e1460136a4e4`.
Its frozen fast-dev bundle passed M1 1/1, M2 9/9, recursive M3 2/2,
preceding-child 1/1, prepared-child 2/2 and catalog 1/1. The annotated tag
`accepted/m1-m2-m3/20261010-2a174f86` binds the exact descriptor and retained
qualification evidence. New source requires a newly qualified matched bundle.
Preserve the existing human-operated servers.

Successfully captured artifact bytes remain valid while any owner retains them,
even if their old origin or materialization files change or disappear. A parent
reload changes current selection; it does not revoke a detached capture. Fresh
acquisition, current source/import/negative-lookup/package selection, and newly
produced output verification remain fresh. Content equality grants no producer,
lexical, instance or execution authority. Worker replacement rehydrates bytes;
GHC decoding remains tied to the actual NameCache owner. Never replay uncertain
compilation or effects to recover transport.

## Implementation owners

1. **Shared artifact bytes.** Introduce opaque `Tidepool.ArtifactBytes`: strict
   bytes plus their computed, forced SHA-256, with derived length/content key.
   No unchecked bytes-and-seal constructor, paths, budgets or GHC state. Replace
   duplicate request payload wrappers, path-only finalized payloads, separate
   graph bytes/seals, and adjacent encoded Core, session and original-interface
   holders. Retain semantic admission and decoded GHC distinctions. Admissions
   own their selected bodies; request owners own receiving budgets and bindings.
   Remove recursive whole-request capture wrappers. Materialize from held bytes,
   without reopening old artifact files. Do not generalize this into unrelated
   runtime values, command output or source snapshots.
2. **Owned transport and compact manifests.** Rust artifact owners retain sealed
   memfd arenas per acquisition/output generation, shared by immutable slices.
   Seal writes, growth, shrinkage and further seal changes. The continuation
   envelope carries a bounded arena table with `/proc/<owner-pid>/fd/<fd>` and
   sealed extent; each part references an arena index and checked offset/length.
   Logical artifact paths and content identity remain separate. Authenticate
   misses and charge every receiving selection, including hits. Confirmed
   compiler work owns leases through closure; durable recovery stores ordinary
   authenticated files, never process-local endpoints. Same-user workers with
   visible owner PIDs are supported; unavailable transport refuses explicitly.
   Exact-scope v13 replaces repeated outlines with exact owner/census references
   and selected ordinals. The existing census retains its index and ordered full
   projection once. Candidate v11 carries the same acquisition transport.
   Preserve exact selection versus availability and expanded bounds. Migrate
   both readers/writers, generated fixtures and docs together; reject old wire
   versions. No new worker-context protocol or legacy adapter. Persistent fixture
   exports explicitly use fresh-file acquisition because their producer exits.
3. **Single terminal publication.** Stage certified products, extend retention,
   then publish once per completed compiler segment. Standalone publication is
   immediate; composed retention publishes no intermediate receipt. Admission
   and changed extensions establish structural proofs. Terminal publication
   checks current observations and newly produced outputs, not historical
   captured files. Do not share observations over intervening compiler work.
4. **Complete native renderers.** Observe actual image keys and lifetimes first.
   Retain immutable native target/group/literal images on a renderable renderer
   before publishing Ready. Factor existing code certification and reachable
   group selection from scoped installation; do not widen Ordinary proof guards
   or invent retained runtime IDs. Fresh bindings, domains, scopes, CAFs and
   machines remain per invocation. Preserve typed frontend/native failure,
   cancellation, single-flight retry and confirmed-close rules. Opaque and
   unavailable renderers retain no native bundle.
5. **Static host provenance.** Carry one immutable selected-fact plan with sealed
   compiled identity, validating paired proofs once. Resolve current runtime
   facts on each invocation. Do not retain the full provenance object if it
   closes a renderer/context ownership cycle. Recovery materialization returns
   its already-issued canonical references for reuse by exact artifact identity;
   preserve durable filenames, historical versions and dependency ownership.

Root owns contracts and integration. Sol owners implement in the provisioned
request-snapshot, declaration-index, entry-handoff, publication-reuse,
component-recovery, packaged-installers and harness-perf-cohorts checkouts.
Coordinate exact shared functions before editing. Each worker compiles affected
production and test consumers early, executes counted checks and supplies small
qualified commits. Independent builds use measured cgroup/process peaks and host
headroom; there is no build-owner queue. Luna reviewers check bounded generators,
fixtures, reports and migration coverage; fresh Sol reviews cover failure paths.

## Evidence and acceptance

ImageRegistry, call-timing and qualification owners with bounded summaries.
Count GHC requests, actual native producers and machine installations separately.
Measure hit lookup/validation/wait costs and failed or abandoned work. Join
issuer IDs, monotonic timestamps and sequence; tolerate buffered late details.
Missing evidence is unknown, not zero. Retain allocation/GC, RSS, arena bytes/FDs
and native code independently. Keep detailed tracing bounded and opt-in.

Freeze a telemetry baseline, then run three paired warm eight-phase/three-actor
comparisons per fast-dev/production profile, alternating order. Run one matched
production cold prepared-child 2/2 pair, each with preceding-child 1/1. Add a
targeted validation/renderer diagnostic pair and one same-artifact trace-overhead
control. Preserve shared-load conditions; medians/ranges from three pairs are
not tail-percentile evidence. Report structural deletion of work separately
from measured speedups.

Extend maintained Rust proptest and Haskell QuickCheck suites with independent
models. Cover acquisition, path deletion/replacement, cache eviction, worker
replacement, cancellation, detached survival and last-reference release. Keep
fresh corruption and current-selection refusal controls. Test ordinal/range
overflow, truncation, budgets, role/producer mismatch, shared graphs and aliases.
Publication tests prove one proof per segment and no premature receipt.
Renderer controls distinguish one native producer per exact live key from twenty
fresh installations, including bounded concurrent consumers, failure/retry,
stale admission after a hit, unrelated retained imports and final release.
Compare static provenance with independent recomputation and test ownership
cycles. Calibrate important generators with reverted deliberate faults.
