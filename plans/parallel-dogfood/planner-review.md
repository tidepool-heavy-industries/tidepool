   first-cause, disposition, roots/storage and cleanup semantics, including the
   minimum `session/persistent.rs` enforcement needed to prevent unsafe reuse.
   Applications owns reconnect/recreate/status and source-only recovery consumers.
   Coordinator reserves any further `registry.rs`, `supervisor.rs`, `recovery.rs`
   or binding edits by actual mechanism before edits begin. Do not put JIT
   integrity recovery into the durable declaration manifest: the inspected
   `session/recovery.rs` explicitly contains source, not live values/handles.
   M2's checked runtime consumer must reject reuse after integrity failure without
   waiting for A7 UI wiring. The handoff needs concrete reusable-language-error,
   unavailable-integrity-failure, and cancelled-suspended-work examples.

2. **Applications frontier accepted.** A4 need not wait for native admission.
   A0 must deliver a narrow working live-binding/dispatcher fixture seam, not
   only shared type declarations that host-delivery can consume only through
   mocks. Native admission and host delivery can develop together; acceptance
   joins at the real native owner. The second accepted-work/process/resource
   scaffold precedes A5/A6 forks; it is lead-checked, not another mandatory root
   meeting. Reserve native-session file overlap before A2 and A6 run together.
   Preserve the actual persisted `--destination-local --after-call` boundary.

3. **Package identity accepted with evidence limit.** Require an explicit pinned
   binary and package/source evidence in isolated fixtures; explain the closure
   suffix mismatch without changing live environment variables. A version string
   alone is not provenance or behavioral compatibility proof. A0 owns the actual
   executable/hash/package relation and the real PTY/provider baseline.

4. **Engine first scaffold must not prejudge M1.** Start M0 with the independent
   outcome vocabulary, baseline fixtures/costs, and a support inventory whose
   unverified items remain explicit. Do not require an exhaustive new projection
   or freeze `PreparedProgram` layouts before observing real prepared STG.
   Provisional vocabulary is useful shared reasoning; public unused schema types
   are not a prerequisite for M1/M2. M1 actual output plus the declared Astra
   decision establishes the checked M3 constructor and consumer scaffold.

5. **One signature/layout truth.** The proposed repr signature/layout, codegen
   ABI and heap layout modules need explicit nonduplicating roles at M3:
   repr validates semantic representations/declarations; codegen lowers the
   authoritative signature to transport; heap owns physical object/header/trace
   descriptors. Adapters, allocation and GC consume those owners rather than
   reconstruct independent tables. Include zero-width semantic arguments,
   oversaturation, mixed roots and a large result in the shared ABI examples.

   there are no external TPLR consumers. Change writer/reader/fingerprints together,

   M6 still needs the live-machine drain/replacement and lost-retained-value
