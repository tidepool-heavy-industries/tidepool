# Restart the two delivery lanes

Resume A0–A8 and M0–M7 on this repository with the current workspace-fork
implementation. This is a new Shoal wave from Git, not resurrection of old actors.
The external supervisor handles cache-reuse validation, build/process watching,
disk growth and usage analysis. Workers own product implementation and its checks.
There is no agent-count cap. The operator may stop a troubled run; preserve
committed partial branches and concrete handoffs when asked to wind down.

## Astra planner's assignment

Read this file, `planner.md`, and the two short lane maps. Use the existing product
designs; investigate only enough owning source to choose sound dependencies and
context boundaries. Have Sol inspect detailed saved work through `saved-work.md`.

Write a compact execution plan before implementation expands:

1. Establish shared product intent and cross-lane ownership with the coordinator.
   Two Sol leads explain the remaining work, proposed first forks and doubts in
   their own words. Review their understanding once and give concrete corrections.
   Reuse the previous review's substantive decisions; revisit changed assumptions.
2. Plan several recursive scaffold → fork → integrate cycles per lane. Name the
   next ready tasks, shared contract, owning files, source and decisive checks.
   Describe later cycles by prerequisites, rather than inventing every future leaf.
3. For each frontier, identify what belongs in the inherited context before
   `unfold`, what a child reads afterward, and which work benefits from selected
   fresh context. Fork siblings while their common investigation is still useful.
   Each child should inherit decisions it can act on immediately.
4. Mark bounded Astra work where cognition matters: native admission/custody,
   real GHC handoff/schema, and calling/layout/root correctness. An Astra may own
   a hard implementation repair as well as advise. Give it evidence, authority,
   a concrete deliverable and a Sol integration owner. Avoid standing Astra
   bookkeeping nodes; do not kill useful experts at arbitrary token limits.
5. Delegate execution and routine decisions. Sol leads implement substantive joins
   and recursively fork independent obligations; the coordinator integrates both
   lanes. Astra receives consequential questions and selected outcomes.

Sol Medium suits lane leads and substantial implementation; Low suits bounded
leaves and checks. Scale the tree to independent work, without headcount targets.
Prefer a useful engineer with several local cycles over chains of managers that
only relay messages. Reviews cover concrete risk and integrated behavior, not a
mandatory new worker at every stage. Shared scaffolds need usable contracts and
consumer examples, not a broad battery before any child can start.
