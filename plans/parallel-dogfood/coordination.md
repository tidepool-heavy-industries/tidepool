# Coordinator: readbacks, shared seams, integration

Use generic `Task` / `componentLead` with
`childWithProgress @Attention @Delivery`; the selected `.shoal/plans/run.md`
contains invocation and watch syntax. Graph task constructors are unrelated
examples. Every task carries an exact committed source, relevant plan path,
owned outcome and acceptance.

## Initial planner checkpoint

Each lead commits `applications-readback.md` or `engine-readback.md` here in its
checkout. Explain, concisely and in its own words:

- Normal behavior and one awkward failure, with actual owners.
- First shared scaffold, ready child tree, and later integration frontiers.
- Concrete files/APIs, checks, dependencies and challenged assumptions.

Publish artifact commit/path and unresolved questions through Attention; keep
Delivery pending. Consolidate coupled choices for the external Astra planner.
Record its accepted corrections and release scope in `release.md`, incorporate
that source, and steer the pending owners. Do not queue a new request behind
pending Delivery. Confirm steering presentation; use the ordinary owning TUI if
transport fails. The external planner is not a Shoal actor.

## Resolve overlaps before edits

| Seam | Owner / handoff |
|---|---|
| Codex session, input, completion; host/process lifecycle | Applications |
| Execution schema, evaluation, heap and machine | Engine |
| Runtime/session cleanup, failure and recovery | Agree exact mechanism/files: engine supplies machine contract; applications owns recovery consumer |
| Repr persistence versus execution schema | Separate file owners and reserve migrations |
| Effect schemas/generated consumers | Existing owner; coordinate any cross-lane change |
| Shared manifests, locks, release pin and combined package | Coordinator integrates lane proposals |
| Curated prompt package | Separate author; preserve its work |

Shared owners deliver usable consumer wiring early. Avoid whole-crate locks.
Integrate reviewed slices at exact source and check the resulting head. Keep
`status.md` at real joins: accepted heads/slices, remaining gates and next owners.
Broad verification belongs at integration/release boundaries.

Lane maps declare Astra slots; consult when their frontier needs a concrete hard
decision. Additional expensive engagements go to the planner. Do not hard-kill
useful in-flight experts. Human-requested RSI uses selected outcomes and evidence,
not routinely forwarded raw histories.
