## Acceptance

- Independent scoped fixed-point histories cover ordinary and preseeded
  projections, recovery/merge, hidden custody, wrong-scope equal payloads and
  proof-only siblings.
- A real first-root private qualification warms shared facts; a later root
  without that qualification must still refuse. Pair it with a permitted
  control and preserve typed first-refusal ordering.
- Ownership tests retain real resources after intermediate owners drop and
  release them after the final owner. Pointer identity alone cannot prove that
  duplicate construction was avoided: interning can conceal that work.
- Count construction and traversals at the operation performing them, with a
  positive control and independent semantic assertions. Small shared-graph
  histories vary request count independently of dependency count.
- Compile normal and test callers, run deduplicated counted component controls,
  then measure the same frozen packaged workload before/after. Report full
  phase coverage, failures, cold/warm work, source/profile and resource pressure.
  Actual authored-Persona acceptance remains a distinct check.
