## Ownership rules

- Structural tests construct current typed data. They do not issue compiler
  authority. Exhaustive encoders and required fields make schema drift visible.
- Buck generates immutable compiled fixtures from declared source, compiler,
  package, target and ordered-root inputs. Tests consume runtime resources,
  rather than embedding generated blobs in Rust executables.
- Production compiler, admission, actor and resource owners issue execution
  authority. Tests use these entrypoints for success and recovery claims.
- Rust browser projections own generated schemas, TypeScript types and runtime
  validators. Truly opaque tool/provider data remains explicitly opaque.
- One matched release bundle owns compiler/runtime/assets/schema identities.
- Negative codec and historical rejection fixtures remain valid, but every
  semantic refusal case first establishes a valid control.
