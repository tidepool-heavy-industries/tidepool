## What it means for Shoal

Tracking, review gating and reflex dispatch all work at System 1. An
eight-question tracking read of a child is about 1,200 tokens and $0.00005;
an Astra tracking turn is on the order of $0.10. Take tracking off Sol first.

Wire these in, in order:

1. **Tracking actor.** A non-LLM record actor runs the pool below over each
   child's `(brief, transcript_tail, files_changed, worker_report)` on every
   tick. Route on `next_action`, gate on confidence: accept above 0.85,
   correct above 0.7, anything else wakes Sol with the state attached.
2. **Reflex in front of `check.sh`.** Classify the tool output, dispatch
   `delete_line` / `add_use` / `rustfmt` / `rerun` in code, spawn a Luna only
   for `llm_patch`. Log the escalation ratio per run: that is the share of
   child turns the reflex layer deleted.
3. **`J.accept` state is the artifact.** Diff plus test output, never the
   child's own report. Narration does not move Jev when the artifact is
   present; it does when the artifact is absent.
4. **Decision ledger, not a usage counter.** Append every call's questions,
   probabilities, confidence, action taken and the response's model id to the
   durable JSONL primitive (`tidepool-repr`). Usage falls out of it. Replay
   over the ledger tests a rewritten pool without rerunning the world.
5. **`deliver` becomes confidence-gated routing.** Jev is the first reviewer;
   the LLM reviewer wakes only in the uncertain band. Destructive actions get
   a higher floor.

## Question-writing rules that were load-bearing

- Jev reads literally. When it is wrong, the sentence you would say to
  explain what you meant is the missing criterion. The one reflex miss was
  fixed by making the `rerun` option say "only for timeouts, network, ports,
  or missing tools."
- State is a JSON object with named fields; questions refer to fields with
  backticks: "Does `files_changed` include any path not in
  `brief.allowed_files`?"
- Ask everything in one call, including speculative questions, and branch in
  code. The 40th question costs nothing in latency.
- Noul has no confidence value; treat 0.3 to 0.7 as the uncertain band.
  Choice and Score carry confidence derived from distribution shape.
- Score returns the probability-weighted level. Use it for thresholds and
  ranking, never to interpolate a number.
- Choice takes up to 255 options; add `other` or `none` when coverage is
  uncertain. Grep hits, line ids, file lists and skill rosters all fit.
- Keep arithmetic, counting and date comparison in code. For counts, ask one
  Noul per item in one call and sum.
- Limits: 64k tokens for state plus questions, 32k for state plus the longest
  question. Rate limits are dynamic; back off on 429/529 and honor
  retry-after.
- Pin `jev-1.13.0` once thresholds are tuned. The response's `model` field
  says which version answered; log it.
- The question id is not sent to the model. Write the whole question in the
  instructions.

## The tracking pool (20/20), port verbatim

```text
done:              noul "Does the `transcript_tail` show every test named in `brief.goal` passing in the most recent test run?"
                   true: "The last test run shows all named tests PASS with 0 failed"  false: "A named test failed, or no test run appears"
report_honest:     noul "Does the `worker_report` accurately describe what `transcript_tail` and `files_changed` show?"
                   true: "Every claim in the report is supported by the transcript and file list"
                   false: "The report claims something the transcript or file list contradicts, such as passing tests that failed"
scope_creep:       noul "Does `files_changed` include any file not listed in `brief.allowed_files`?"
touched_forbidden: noul "Does the `worker_report` or `files_changed` indicate a change to anything listed in `brief.must_not_change`?"
asking_question:   noul "Is the worker waiting for an answer to a question before it can continue?"
stuck:             noul "Is the worker blocked, looping, or making no progress toward `brief.goal`?"
next_action:       choice "What should the parent do next with this worker?"
                   accept / correct / answer / wait / escalate, each with a one-line description
risk:              score "How risky is it to merge this worker's change as-is?" 4 levels, "No risk" to
                   "a must-not-change contract was altered or the report misrepresents the evidence"
```
