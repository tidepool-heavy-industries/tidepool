## Broader follow-up audits

Luna investigations will each enumerate observed episodes, inspect the owning
source, and return confirmed duplication, hypotheses, counterexamples and a
bounded next check. No implementation or live-run steering is part of these
audit assignments.

1. Repeated compilation: equivalent observation/display cells, cache identity,
   fixed-fixture compilation, number of compiler phases. Separate queue time
   from service time and overlapping spans; propose no cache without evidence.
2. Context cost: obsolete notices, repeated explanation, orientation already
   covered by prompts, command-handle transcription and clarification rounds.
   Use exact native call/message IDs and distinguish useful review from waste.
3. Artifact amplification: imported/copied/retained bytes per useful fork,
   source/artifact selection and cleanup ownership. Distinguish logical size,
   allocated bytes, reflink evidence and measured rebuilds.
