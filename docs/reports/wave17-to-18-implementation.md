## Intent

Expose small composable Haskell workflows to an Astra root managing parallel Luna
feature-area trees. Jev selects tightly instructed semantic branches; deterministic
code owns state, source identities, authority, jobs and continuation. Measure real
bookkeeping sequences and retained evidence rather than claiming savings from use
counts. Wave18 is a standalone browser harness milestone, not an adapter launch.
