  Console: Print text output.
      verbs: say, sayShow
  KV: Persistent key-value store.
      verbs: kvGet, kvSet, kvDel, kvKeys, kvClear, kvKeysP, kvInfo, kvCas
  Fs: Read and write files (sandboxed to server working directory).
      verbs: readFile, writeFile, appendFile, listDirectory, doesFileExist, doesDirectoryExist, getFileSize, fsMeta, getCurrentDirectory, glob, grepGlob, readGlob, update, updateAll, planUpdate, updateJ, insertAfter, writeChecked, fileHash, writeCheckedIf
  Http: JSON I/O.
      verbs: httpGet, httpPost
  Exec: Run shell commands and capture output.
      verbs: run, runIn, runArgv
  Lsp: Semantic code-graph navigation via a language server (rust-analyzer, .rs).
      verbs: lspWhere, lspCallers, lspCallees, lspRefs, lspDef, lspHover, lspRename, lspDiags
  Llm: Call an LLM for classification, extraction, or judgment.
      verbs: llm, findTally, tallyList
  Git: Read-only git repository queries.
      verbs: gitLog, gitStatus, gitDiffStat, gitShow
  Time: UTC wall-clock access (epoch milliseconds).
      verbs: getCurrentTime
  Ask: Suspend execution and ask the calling agent a STRUCTURED question.
      verbs: ask, isOpt, innerSchema, schemaToValue
  RunLLMTurn: Suspend for a TYPED answer.
      verbs: runLLMTurn, runLLMTurnFork, runLLMTurnFanout, renderInvocationExit, runLLMTurnSited, runLLMTurnForkSited, runLLMTurnFanoutSited, freezeContext, runLLMTurnBranch, runLLMTurnBranchSited, runLLMTurnBranchLabeled, runLLMTurnBranchLabeledSited
  Fork: Spawn parallel sub-answerers and gather their typed answers.
      verbs: forkSited, forkAllSited
