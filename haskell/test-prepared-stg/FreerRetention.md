# Freer retention boundary

`freerRequest` is a real `freer-simple` `send` program.  The prepared corpus
projection compiles and admits its artifact, but the legacy corpus runner
recursively observes the returned `E` and therefore stops at its function
continuation.  The Wave 6A `PreparedMachine` retained-result path needs a
descriptor-only outer inspection boundary to expose that continuation as an
opaque managed handle instead of forcing it.

The fixture intentionally supplies no expectation: it pins the artifact and
the current observation boundary without inventing an effect interpreter.
