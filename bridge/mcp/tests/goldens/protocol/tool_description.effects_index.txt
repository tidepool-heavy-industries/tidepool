  Console: Print text output.
      verbs: say
  KV: Persistent key-value store.
      verbs: kvGet, kvSet, kvDel, kvClear, kvKeysP, kvInfo, kvCas
  FsRead: Read files and filesystem metadata (sandboxed to server working directory).
      verbs: readFile, listDirectory, doesFileExist, doesDirectoryExist, getFileSize, fsMeta, glob, grepGlob, readGlob, planUpdate, fileHash
  FsWrite: Mutate files (sandboxed to server working directory).
      verbs: writeFile, appendFile, update, updateAll, updateJ, insertAfter, writeChecked, writeCheckedIf
  Http: JSON I/O.
      verbs: httpGet, httpPost
  Exec: Run shell commands and capture output.
      verbs: run, runIn, runArgv
  Llm: Call an LLM for classification, extraction, or judgment.
      verbs: findTally, tallyList
  Git: Read-only git repository queries.
      verbs: gitLog, gitStatus, gitDiffStat, gitShow, gitLogNumstat
  Time: UTC wall-clock access (epoch milliseconds).
      verbs: getCurrentTime
  Entropy: Randomness.
  Ask: Suspend execution and ask the calling agent a STRUCTURED question.
  RunLLMTurn: Suspend for a TYPED answer.
      verbs: runLLMTurn, runLLMTurnFork, runLLMTurnFanout, renderInvocationExit
